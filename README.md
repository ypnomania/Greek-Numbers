# Greek Numbers

Windows 98 风格的希腊语数字听写练习器，提供中文界面。基于 `greek_number_listening_v7_win98.html` 整理，使用浏览器语音合成与本地学习档案，无需后端或构建工具。

**在线使用：<https://ypnomania.github.io/Greek-Numbers/>**

## 功能

- **数字听写**：支持 0–99、0–999、0–9999，可选择自适应、单项诊断、位数均衡、完全随机和到期复习。
- **电话听写**：支持十位号码的多种分组方式及逐位练习。
- **练习设置**：5 秒限时或自由练习、语速、专项数词、页面数字键盘或系统键盘。
- **学习档案**：查看作答记录、单项熟练度、近 7 天统计和输入差异。
- **数据备份**：导出、导入 JSON 备份；记录保存在当前浏览器的 IndexedDB 中。

## 开始使用

1. 打开在线页面，展开「设置」。
2. 在「希腊语声音」中选择可用声音；如果没有声音，先在设备上安装或启用希腊语语音，再点击「刷新语音」。
3. 选择数字或电话、训练方式和语速，点击「开始」。
4. 听到语音后输入数字，在「档案」查看结果。

语音使用浏览器的 Web Speech API，声音是否可用取决于浏览器和操作系统。页面会标出声音来自「本机」还是「联网」；联网声音可能需要网络连接。Win98 是界面风格，本项目需要支持现代 Web API 的浏览器。

学习记录不会由本应用上传到 GitHub，也不会自动跨设备同步。清除浏览器站点数据会删除本地档案，请定期导出备份。从下载的 HTML 切换到在线页面时，原有档案不会自动迁移：请先在旧页面导出，再在在线页面导入。

## 本地运行

直接用浏览器打开 `index.html`，或在项目目录启动静态服务器：

```sh
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。建议使用固定的地址、端口和浏览器，便于继续使用同一份本地档案。

## GitHub Pages 部署

本项目采用 GitHub Pages 的分支发布：`main` 分支、`/(root)` 目录。无需安装 npm 依赖、执行构建或配置部署密钥。

在仓库 **Settings → Pages → Build and deployment** 中，选择 **Deploy from a branch**，然后选择 `main` 和 `/(root)`。后续将修改提交并推送到 `main`，GitHub 会自动重新发布；部署状态可在仓库的 **Actions** 和 **Settings → Pages** 查看。

发布地址为 <https://ypnomania.github.io/Greek-Numbers/>，已启用 HTTPS。仓库为公开仓库。

## 维护

修改 `index.html` 后，至少检查数字 / 电话 / 档案切换、语音选择、练习流程、设置保存，以及备份导入导出。页面不依赖 CDN、第三方脚本或外部字体；添加资源时使用相对路径，确保在 `/Greek-Numbers/` 子路径下正常加载。

档案回归测试使用 Node.js 自带的测试运行器，不需要安装依赖：

```sh
node --test tests/persistence.test.cjs
```

本仓库修复了原 v7 页面中电话「混合分组」记录导致档案重新加载失败的问题。新记录会保留实际播放的分组；旧版紧凑记录未保存该信息，读取时按两位一组还原显示，保留原有答案和成绩。新旧记录均保留「混合分组」的统计分类。
